# EHRSQL PostgreSQL Import

Generated by:

```bash
python3 EHRSQL/convert_sqlite_to_postgres.py
```

Loaded into the Docker PostgreSQL container `ai-agent-postgres` as:

- `ehrsql_eicu`
- `ehrsql_mimic_iii`

The import uses the benchmark-provided PostgreSQL DDL files as the schema
source:

- `EHRSQL/code/dataset/ehrsql/eicu/eicu.sql`
- `EHRSQL/code/dataset/ehrsql/mimic_iii/mimic_iii.sql`

For loading, `schema_no_fk.sql` removes only `FOREIGN KEY` clauses. Primary
keys, uniqueness constraints, column names, and column types are preserved.
This avoids PostgreSQL load failures from benchmark relationships that are
polymorphic or not directly enforceable, while keeping the databases suitable
for read-only SQL and graph-agent evaluation.
